# Longer-Loading-Music
Extends spore's loading screen music to be just over 25 minutes so you now have more to listen to while waiting for those super complex adventures to load in!
First plays the full version of Brian eno - Hopeful Timean intersect (The vanilla loading music), then seamlessly transitions into Brian eno - Kazakhstan. 

This mod is incompatible with Stream safe music, both because it effects the same files and because both songs are heavily copyrighted and will likely get your video taken down if they're included in it. Please remember to uninstall this mod or mute the in game music before you record!

Should be 100% compatable with Share safe music, and will actually compliment it nicely by giving you a much longer ambient track to use for your adventures!
